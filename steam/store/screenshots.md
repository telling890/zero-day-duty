# 商店截图：顺序、解说词与重拍要求

## 规则

- Steam 要求**至少 5 张**，最多 20 张；建议 6–10 张。
- 比例 16:9，最低 1280×720，**建议 1920×1080**（这里的图已统一成 1920×1080）。
- 不要放文字标语、价格、其它商店 Logo、"即将推出"字样。
- 第一张图决定点击率：要一眼看出「这是个安全值班的策略游戏」。

## 现在的图有什么不足（要不要重拍）

1. 原图是 Pygame 1280×720 直接抓的，上采样到 1920×1080 后文字边缘略软。
   如果在意，可以给游戏加一个 `--scale 2` 渲染开关再重抓（属于代码改动，可后续做）。
2. 缺一张「命令行 / 自动化剧本」的画面——这是本作差异点，**强烈建议补拍**。
   网页版（`docs/play`）已经有现成截图：
   `web/tests/screenshots/terminal-boot.png`、`script-open.png`，可直接用。
3. 缺「失败结局」的图：能说明「过度防御也会输」，对转化有帮助。

## 预告片（可选但很值）

Steam 首页曝光权重最高的素材。最省事的做法：

```
1. 用 OBS / Win+G 录 3–5 分钟真实操作
2. 剪 40 秒：3 秒标题 → 15 秒处置流程 → 10 秒终端/脚本 → 8 秒结算 → 结尾 Logo
3. 1280×720 或 1920×1080，H.264，无版权音乐（或自己合成）
```

游戏里的音效是 WebAudio/合成音，没有版权风险，可以直接录。

## 重拍脚本

```powershell
# 1. 重新抓 Pygame 截图（跑一遍游戏，F12 截图，或复用现有）
# 2. 统一成 1920x1080
python steam\scripts\make_screenshots.py
# 3. 自检
python steam\scripts\check_assets.py
```
