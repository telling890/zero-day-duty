## 关于这款游戏（长描述）

```
08:00 之前，把六条攻击链全部掐断——同时别把公司业务关停。

《零日值班》是一款关于「取舍」的回合制安全运营游戏。你是「云栖示例科技」今晚唯一的值班员，
22:00 接班，08:00 汇报，中间只有 10 个回合。每条攻击链都要走完四步：
调查 → 控制 → 清除 → 恢复。少一步不算解决，顺序错了等于白干。

■ 四步处置，一步都不能省
只隔离不清除，结算会扣分；清除根因后不恢复业务，服务继续中断、收入继续掉。
失败条件也不止一种：安全度归零、数据完整度见底，或者你为了安全把业务全关掉，
可用性连续三回合过低——同样判负。

■ 三种输入方式，同一套规则
- 点击：告警、操作面板，边看边判断
- 命令行：按 ` 打开处置终端，`scan PC-01`、`isolate PC-01`、`clean PC-01`，Tab 补全、↑/↓ 翻历史
- 脚本：按 C 打开自动化剧本，写几行 Python 风格的 ZDD Script 批量处置
三种方式共用同一套行动点和资金，没有免费捷径；脚本也不会替你判断误报。

■ 每个决定都有代价
隔离会中断业务，关停会掉收入，买加固要花预算。第 4/5/7 回合还有剧情决策，
选项只写直接成本，真正的后果可能延后一到三回合才显现。

■ 可复现的一夜
同一随机种子 + 同一难度，事件顺序与结果完全一致。适合复盘、对比打法，
也适合课堂上一局一局地讲。

■ 新手也能上手
15 页图文教程 + 6 步沉浸式带练：聚光灯压暗画面，只圈出这一步该点的位置，
点击、命令、脚本三条通道各走一遍；打不动命令可以一键把命令填好。

■ 本作是虚构的
所有公司、人员、IP、域名、告警与数据均为虚构，IP 使用文档保留地址段；
游戏不连接任何真实网络、不执行任何系统命令、不收集任何用户数据。
```

## 主要特色（Steam「特色」区块，可贴 5–6 条）

```
回合制安全运营：10 回合、6 条攻击链、每回合 6 点行动点
完整处置链：调查 → 控制 → 清除 → 恢复，少一步都不算解决
三种输入通道：鼠标点击 / 处置终端命令 / ZDD Script 自动化剧本
风险与误报：调查才知道真假，下一跳提示决定先防哪里
经济取舍：隔离断业务、关停掉收入、加固吃预算
可复现：同种子同难度，结果一致
```
