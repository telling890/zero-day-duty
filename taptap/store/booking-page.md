# 预约页文案（TapTap · 预约 / 敬请期待阶段）

> 这个阶段**不开放下载**，所以不需要版号；文案可以更轻，重点是把「这是什么游戏」讲清楚、
> 让人愿意点预约。等资质齐了再把状态改成正式上线，届时用 `../README.md` 里的正式文案。

```
08:00 前掐断六条攻击链，同时别把公司业务关停。
```

## 简介（前 50 字是重点，整段控制在我 180 字内）

```
你是深夜唯一的安全值班员。10 个回合、6 条攻击链，每回合只有 6 点行动点。

调查、控制、清除、恢复，四步缺一不可：只隔离不清除会扣分，清除后不恢复业务，收入继续掉。
下手太重也不行——把业务全关停，同样判负。

回合制安全运营，支持鼠标、命令行、自动化脚本三种操作方式。所有公司、IP、数据均为虚构。
```

## 开发者的话

```
一个人做完的小项目。最初只想讲清一件事：为什么安全处置有先后顺序。

先控制再清除、清除完要恢复，少一步都不算解决——这句话做成游戏以后，比讲十遍 PPT 都直观。
后来又在里面塞了一个能写脚本的自动化引擎，因为真实的夜班就是这样：能批量的活，没人愿意点一百次。

现在还在打磨中，欢迎在评论区告诉我你想要什么玩法。
```

## 预约页 FAQ（选填，但很能降低误解）

**Q：多久能玩到？**
A：目前在做上线准备（资质与测试），开放后会第一时间在 TapTap 通知预约玩家。

**Q：支持什么平台？配置要求高吗？**
A：首发 Windows PC，1280×720 起，集成显卡可跑，无需联网。

**Q：收费吗？**
A：计划买断制，无内购、无广告；具体价格上线时公布。

**Q：需要联网吗？**
A：完全离线，不收集任何数据。存档写在本机游戏目录。

## 预约阶段**别写**的东西

| 别写 | 原因 |
| --- | --- |
| 具体的上线日期 | 资质（软著/版号）时间不可控，写死会被玩家和平台同时追责 |
| 「免费」 | 还没定；且免费也需要版号才能开放下载 |
| 联系方式 / 群号 / 兑换码 | TapTap 明确禁止在简介和开发者的话里放这些 |
| 其他平台链接 | 只允许 Steam 与 TapTap 详情页链接 |
| 「送激活码」「预约抽奖」 | 预约期做活动要走平台的活动报备，别自建 |
