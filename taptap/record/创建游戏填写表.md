# 「创建游戏」逐字段填写表

> 你现在这页：TapTap 开发者服务 → 首页 → 右上绿色 **创建游戏**。
> 下表左边是后台字段，右边是照抄的值。标「文件」的直接上传对应文件。

## 〇、这一屏只填 3 个字段

| 位置 | 填 / 勾选 | 注意 |
| --- | --- | --- |
| 游戏名* | `零日值班` | **纯中文、不加冒号/版本号/口号**（后台提示：标题请勿添加任何无关词缀与特殊符号） |
| 游戏类型 | `策略`（没有就选 `模拟`，再没有才用 `休闲` 兜底） | 默认显示「休闲」，一定要改 |
| 游戏平台* → 电脑/主机 | **只勾 `TapTap Windows 版`** | 见下方警告 |

然后点右下「创建游戏」。

> ⚠️ **不要勾 `Steam 平台`**：那是给「已在 Steam 上架、要同步到 TapTap」的游戏用的，
> 会要求 Steam 侧信息；我们 Steam 还没上（AppID 都没申请），勾了只会在审核时被卡。
>
> 顶部那条「创建 H5 或 TapTap 制造游戏，请前往新版后台」与我们无关——我们走的是 PC 包，
> 老后台的「游戏包管理」就能传。等以后要上 H5 在线玩，再去新版后台单独建。

## 一、基本信息（创建后再补，改起来麻烦）

| 后台字段 | 填什么 | 备注 |
| --- | --- | --- |
| 游戏名称 | `零日值班` | **尽量一次定好**，改名要重新走审核；不能带特殊符号 |
| 英文名（如有该字段） | `Zero-Day Duty` | 没有就跳过 |
| 厂商 | `telling工作室`（默认已选） | 别点新增厂商 |
| 游戏类型 | `策略` 主类型，`模拟` 副类型 | 与 Steam 标签保持一致 |
| 支持平台 | **电脑/主机 → `TapTap Windows 版`** | ⚠️ 别勾 Steam 平台、别勾手机 |
| 发行地区 | `中国大陆`（如需海外再加） | — |
| 语言 | `简体中文` | 只勾这一个，别勾英文 |
| 收费模式 | `买断制`（或「待定」） | 测试阶段不影响；别选内购 |
| 官网 / Steam 页（选填） | `https://github.com/telling890/zero-day-duty` | TapTap 允许填 Steam 链接 |

## 二、简介（直接粘）

```
你是深夜唯一的安全值班员。10 个回合、6 条攻击链，每回合只有 6 点行动点。

调查、控制、清除、恢复，四步缺一不可：只隔离不清除会扣分，清除后不恢复业务，收入继续掉。
下手太重也不行——把业务全关停，同样判负。

回合制安全运营，支持鼠标、命令行、自动化脚本三种操作方式。所有公司、IP、数据均为虚构。
```

开发者的话（有该字段就填）：

```
一个人做完的小项目。最初只想讲清一件事：为什么安全处置有先后顺序。

先控制再清除、清除完要恢复，少一步都不算解决——这句话做成游戏以后，比讲十遍 PPT 都直观。
```

## 三、素材（点上传，选文件）

| 后台位置 | 上传哪个文件 |
| --- | --- |
| 游戏图标（512×512，1:1） | `taptap/materials/icon_512x512.png` |
| 横版封面（460×215） | `taptap/materials/cover_460x215.png` |
| 竖版封面（600×900） | `taptap/materials/cover_600x900.png` |
| 游戏截图（≥3 张） | `steam/store/screenshots/01_gameplay_1920x1080.png`<br>`02_tutorial_guide_1920x1080.png`<br>`04_decision_1920x1080.png`<br>`05_result_1920x1080.png`（这张最像"结果"，可放第 3 张） |
| 游戏库壁纸（3840×1240，选填） | `taptap/materials/wallpaper_3840x1240.png` |
| 宣传图 16:9（选填，测试阶段可跳过） | `taptap/materials/promo_16x9_1920x1080.png` |

> 实机录屏也是「开放下载」才必须，内部测试可以先不传。

## 四、创建之后

| 顺序 | 去哪 | 做什么 |
| --- | --- | --- |
| 1 | 游戏 → **版本发布** / **游戏资料** | 状态确认是「敬请期待 / 预约」，别选正式上线 |
| 2 | 游戏 → **PC 包体管理 → 包体管理** | 上传 `taptap/test-build/零日值班_测试版_v1.6.0.zip`，可执行文件填 `零日值班.exe` |
| 3 | 游戏 → **版本发布 → 测试 → 内部测试** | 勾「仅有测试资格可登录游戏」→ 创建计划 |
| 4 | 内部测试 → 添加测试用户 | 平台选 PC → 导入 `taptap/record/internal-test-users.csv`（先只填你自己） |
| 5 | TapTap PC 版 | 用你的账号登录 → 游戏页「立即自测」→ 下载 → 启动 |

## 五、三个容易选错、选错要返工的

| 别选错 | 后果 |
| --- | --- |
| 电脑/主机没勾「TapTap Windows 版」 | 没有「游戏包管理 / PC 包」入口，包传不上去 |
| 状态选了「正式上线」 | 直接进首发状态，等于承诺随时可下载（我们还没版号） |
| 类型选了「休闲 / 卡牌」之类 | 后续审核的类目要求不同，改类目要重新提审 |

## 六、如果卡在创建这一步

| 现象 | 处理 |
| --- | --- |
| 提示「信用等级不足，无法创建」 | 先去「厂商设置 → 厂商资料 / 厂商首页」补全信息，再试；不行就提工单写明「个人开发者，已有可运行 PC 单机，申请创建游戏」 |
| 提示「名称已被占用」 | 后台禁止加特殊符号，改用无符号方案：`零日值班零点班` 或 `零日值班夜班`（别加冒号/括号/版本号） |
| 创建后找不到 PC 包入口 | 说明没勾「TapTap Windows 版」，去游戏资料里补选平台 |
