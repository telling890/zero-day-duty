# 开测操作卡（一页）

> 目标：让 1 个人（你自己）在 TapTap 上把包下下来、跑起来。
> 不用软著、不用版号。唯一变量是防沉迷（见文末分支）。

## 0. 手上有这些

| 东西 | 位置 |
| --- | --- |
| 上传包 | `taptap/test-build/零日值班_测试版_v1.6.0.zip`（24.4 MB，已自检通过） |
| 启动项 | `零日值班.exe` |
| 图标 / 封面 / 截图 | `taptap/materials/` + `steam/store/screenshots/` |
| 简介文案 | `taptap/store/booking-page.md` |
| 名单模板 | `taptap/record/internal-test-users.csv`（先只填你自己） |

## 1. 建游戏（约 5 分钟）

- [ ] 左侧图标栏 → **游戏管理（商店）** → 新建游戏 → 厂商选 `telling工作室`
- [ ] 游戏名：`零日值班`；简介：抄 booking-page.md 里那段
- [ ] 图标 `icon_512x512.png`、横版封面 `cover_460x215.png`、截图 ≥3 张
- [ ] 状态：**敬请期待 / 预约**（不要选正式上线）

## 2. 传包（约 3 分钟）

- [ ] **商店 → PC 包体管理 → 包体管理 → 上传包体**
- [ ] 选 zip，可执行文件填 `零日值班.exe`，系统 Windows，版本 `v1.6.0`，依赖库：无
- [ ] 传完等状态变成「可用 / 已入库」

## 3. 开内部测试（约 3 分钟）

- [ ] **商店 → 版本发布 → 测试 → 内部测试**
- [ ] 游戏测试设置 → 勾选「仅有测试资格可登录游戏」→ 创建内部测试计划
- [ ] 添加测试用户 → 资格平台选 **PC** → 导入 CSV（先 1 条：你自己的 TapTap ID）
- [ ] 保存（无需审核，即时生效）

## 4. 装一次（约 10 分钟）

- [ ] Windows 装 **TapTap PC 版**，用收到资格的账号登录
- [ ] 游戏页点「**立即自测**」（或开发者给你的自测链接）
- [ ] 下载 → 启动 → 进主菜单
- [ ] 走一遍教程第一页 + 完成 6 步带练
- [ ] 存一次档 → 退出 → 重新进 → 点「继续上次值班」
- [ ] 退出后检查游戏目录**没有** `error.log`

## 5. 通过后再放人

- [ ] 把这 4 项写进反馈表：能启动 / 教程通 / 存档读回 / 无报错
- [ ] 第二批加朋友（改 CSV → 重新导入），**不用重新传包**

## 卡住时的三个分支

| 现象 | 处理 |
| --- | --- |
| 传包报「不支持收录 / 含启动器」 | 我们的包是单 exe、无启动器，正常不会被拦；若被拦，把后台原话发我 |
| 开测试被要求「接入防沉迷」 | 提工单确认内部测试是否豁免（模板见 `内部测试最短路径.md` 第四节）；若必须接 → 走下方 H5 方案 |
| 测试者下载后闪退 | 让对方发 `error.log`；同时你在本机解压 zip 双击验证（`taptap/scripts/verify_test_build.ps1` 已确认退出码 0） |

## H5 兜底方案（防沉迷卡住时）

`taptap/h5-build/零日值班_h5_v1.6.0.zip`（143 KB，纯静态，已验证 index/js/css 全 200）。

- 用法：解压 → `py -3 -m http.server 8080` → 开 `http://localhost:8080/`
- 交给平台：需要公开 https 地址，可以直接用现成的
  `https://telling890.github.io/zero-day-duty/play/`
- 优势：H5 由平台容器跑，启动校验/防沉迷走平台侧，不需要我们接 SDK
