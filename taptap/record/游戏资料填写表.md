## 四、兼容性 / 其他声明

| 字段 | 填什么 |

| 兼容性 | 勾 **无系统要求**（本作离线、无 VR、非 Android） |

## 五、两个容易被打回的点（已经帮你处理）

| 规则 | 我们的处理 |
| --- | --- |
| 宣传图「不得直接使用游戏截图或简单拼贴」 | 用程序化绘制的网络拓扑主视觉，不是截图 |
| 宣传图「不得出现游戏图标」 | 主视觉里没有图标元素 |
| LOGO「只能包含游戏名，不得添加游戏名以外的文字」 | 默认版只写「零日值班」，英文名版本留作备选 |
| 封面「不得出现游戏标题以外的宣传性文字」 | 封面只放游戏名，slogan 全删了 |
| 壁纸「不得出现 LOGO、宣传标题等任何形式的文字」 | 壁纸是纯画面 |

## 六、填完之后

2. **审核期间就能做内部测试**：版本发布 → 测试 → 内部测试 → 创建计划 → 导入名单
3. 包体没传的话先去传：Windows 版本管理 → 包体管理 → 上传
