# 内部测试最短路径（只在 TapTap 上测试）

目标：**让测试用户在你的 TapTap 游戏页下载并玩到**，不上架、不开放下载、不需要版号。
依据官方 [PC 游戏如何在后台传包](https://developer.taptap.cn/docs/en/pc-store/guide/pc-bundle/) 与 [PC 测试计划](https://developer.taptap.cn/docs/en/pc-store/guide/pc-test/)。

---

## 一、先打一个能传的包

```powershell
powershell -ExecutionPolicy Bypass -File taptap\scripts\prepare_test_build.ps1
```

产物 `taptap/test-build/零日值班_测试版_v1.6.0.zip`（24.4 MB）结构：

```
零日值班.exe          ← 启动项，在压缩包根目录
使用说明.txt
测试说明.txt          ← 给测试者看的：怎么进、怎么反馈
saves/README.txt
```

**TapTap 的「纯净包」定义我们已经满足**：打开就是游戏，没有「下载 / 安装 / 获取」这类文案，也不需要启动器。
单文件 exe 天然合规，不需要拆依赖库。

| 后台字段 | 填什么 |
| --- | --- |
| 可执行文件（相对路径） | `零日值班.exe` |
| 操作系统 | Windows |
| 版本号 | `v1.6.0` |
| 依赖库 | 无 |

## 二、后台五步

```
① 商店 → 新建游戏（厂商选「telling工作室」）
   填：游戏名、简介、图标、横版封面、至少 3 张截图。测试阶段这些就够。

② 商店 → PC 包体管理 → 包体管理 → 上传包体
   选上一步的 zip，填启动项配置（见上表）

③ 商店 → 版本发布 → 测试 → 内部测试
   游戏测试设置 → 勾选「仅有测试资格可登录游戏」→ 创建内部测试计划

④ 添加测试用户 → 资格平台选「PC」→ 导入 taptap\record\internal-test-users.csv
   保存后，被导入的账号会收到站内信（最多 100 人）

⑤ 让测试者：Windows 装 TapTap PC 版 → 登录收到的账号 → 游戏页点「立即自测」
```

## 三、测试阶段可以**先不填**的

完整上架才需要这些，内部测试阶段不用一次备齐：

| 项目 | 何时必须要 |
| --- | --- |
| 宣传图 16:9 / 1:1、无 Logo 宣传图 | 首页推荐位、正式开下载 |
| 游戏库壁纸 3840×1240 | TapTap PC 版库内展示 |
| 游戏 LOGO（1280 宽透明） | 正式商店页（测试阶段有图标+封面即可） |
| 实机录屏 | **开放下载 / 试玩才必须**；纯内部测试可先不传 |
| 软著、版号 | 开放下载必须；免费测试阶段非必须 |

> 也就是说：**你现在缺的「录屏」不挡内部测试**，先把包传上去让朋友玩起来。

## 四、唯一需要留意的合规点：防沉迷

官方资质表把「免费测试」的防沉迷标为必需，但**内部测试不对外曝光**（只有被邀请的账号可见、可下载），
实际是否强制接入 TapTap SDK 的启动校验，最好在开测前用一条工单确认：

> 工单分类：商店运营服务支持 / TapTap 功能申请 / PC 专区咨询
> 问题模板：*我们是个人开发者，打算用「内部测试」仅对 100 名受邀用户开放 PC 单机（完全离线、无内购）。
> 这种不对外曝光的内部测试，是否需要接入防沉迷 SDK 启动校验？*

Python/Pygame 目前接不了官方 SDK（只有 Unity / C++ 集成），所以**这条要提前问清楚，不要开测前一天才发现**。

## 五、开测前自测 5 项

- [ ] 下载 zip → 解压 → 双击 `零日值班.exe` 能进主菜单（没装 Python 的机器上测）
- [ ] 新手教程能翻页、能完成 6 步带练
- [ ] 存档写入 `saves\savegame.json`，重开能「继续上次值班」
- [ ] Alt+Tab / 切换到窗口外再回来不崩
- [ ] 正常退出后，游戏目录**没有** `error.log`

## 六、收反馈

给测试者只要三个问题（见 `internal-test-users.csv` 的 note 列）：

1. 卡在哪一步？
2. 哪句话没看懂？
3. 还想不想再玩一局？

这三条比「好不好玩」有用得多，而且能直接指导下一版改什么。

## 七、测完怎么办

- 想继续扩大：改成**封闭式测试**（最多 10 万人，可招募 / 先到先得），仍不需要版号
- 想正式开放下载：补齐软著（+ 版号），状态改成正式上线
- 测试期间**游戏状态保持「敬请期待 / 预约」**，千万别点「正式上线」——那会直接进入首发状态
