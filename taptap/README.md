# TapTap 上架清单（零日值班）

素材已按 TapTap 官方规则生成在 `materials/`。**但先说结论：TapTap 的硬门槛不是「厂商名额」，是资质。**

依据官方文档：

- [游戏物料要求](https://developer.taptap.cn/docs/store/release/publish/material/)
- [PC 游戏资质指引](https://developer.taptap.cn/docs/en/pc-store/guide/pc-gamelicense/)

---

## 一、你遇到的「暂不支持新增厂商」

报错原文：*平台会结合厂商信用等级、认证信息及实际使用情况，综合确定可认证的厂商数量。当前已达到数量上限。*

**先看现状（2026-11 后台截图确认）：你已经有厂商 `telling工作室`，认证开发者 = 个人，信用等级 = C。**
所以这个弹窗只是因为你点了「新增厂商」——**根本不需要新增**，直接在 `telling工作室` 下面新建游戏即可。

顺带说明：你截图停的位置是 **财务与管理 → 厂商设置**，这页只管账号资料 / 厂商首页 / 评价通知，
和「发布游戏」不是一条路。发布入口在左侧图标栏的**游戏管理（商店）**模块。

如果确实需要第二个主体，三条路按成功率排：

| 顺序 | 做法 | 说明 |
| --- | --- | --- |
| 1 | 用**已有的厂商主体**加游戏 | 就是 `telling工作室`，别点「新增厂商」 |
| 2 | 走**个人开发者**入驻 | 你已经是个人认证，个人确实可以直接发游戏 |
| 3 | 提工单申请放开名额 | 开发者中心 → 工单，写明「已完成实名 + 已有软著，申请新增 1 个厂商」 |

### 信用等级 C 意味着什么

信用等级是平台给你分配资源位、审核优先级、可新增主体数量的依据——那个「数量上限」弹窗就是它的直接结果。
提升靠这几件事，按性价比排：

1. **补全厂商资料**（厂商设置 → 厂商资料：联系方式、公司/个人证照、收款信息）
2. **填厂商首页**（厂商设置 → 厂商首页，这个页面玩家点开能看到）
3. **发布并持续维护游戏**（有正式作品后等级会重算）
4. **不要出现违规/侵权/被下架记录**

> C 级不拦你发布，但对新提交的物料审核会更严——所以第一次提交务必把物料和资质一次给全。

## 二、真正卡住上架的是资质

官方《PC 游戏资质指引》写得很直白：

| 资质 | 要求 |
| --- | --- |
| **软件著作权（软著）** | 必填：登记号 + 证书扫描件；非著作权人需授权链 |
| **版号（ISBN）** | 在大陆**开放下载**需要；仅「预约 / 信息展示」暂不需要；无版号不得有任何内购计费 |
| 运营 / IP 授权 | 若素材、剧情、音乐涉及他人 IP，需要完整授权链 |

所以现实路径只有两条：

- **A. 先上「预约页」**：只要物料 + 软著，不开放下载 → 不需要版号。适合先攒关注。
- **B. 等版号下来再开放下载**：PC 单机也需要，周期以月计，个人基本要走代理/出版社。

> 没有软著就先别折腾 TapTap：连审核提交都会被卡在资质那一步。

## 三、物料对照：已生成 vs 还缺

TapTap 的尺寸和 Steam **不一样**，不能直接复用（尤其「封面不得有标题以外的宣传文字」「壁纸不得有任何文字」这两条，Steam 那套带 slogan 的图会被打回）。

| TapTap 要求 | 规格 | 我们的文件 | 状态 |
| --- | --- | --- | --- |
| 图标 \*必填 | ≥512×512，1:1，直角，非白/黑/透明底 | `materials/icon_512x512.png` | ✅ |
| 游戏 LOGO \*必填 | 1280 宽或 720 高，png，<4MB，透明 | `materials/logo_1280x720.png` | ✅ |
| 横版封面 \*必填 | 460×215，png/jpg，<3MB，只许有游戏名 | `materials/cover_460x215.png` | ✅ |
| 竖版封面 \*必填 | 600×900，png/jpg，<3MB，只许有游戏名 | `materials/cover_600x900.png` | ✅ |
| 游戏库壁纸 | 3840×1240，png/jpg，<10MB，**不得有任何文字** | `materials/wallpaper_3840x1240.png` | ✅ |
| 宣传图 16:9 \*必填 | ≥1920×1080，<4MB，必须有清晰游戏名，除游戏名外无其他文字，**不得直接用游戏截图或简单拼贴** | `materials/promo_16x9_1920x1080.png` | ✅ |
| 宣传图 1:1 | ≥1440×1440（竖版录屏封面时需要） | `materials/promo_1x1_1440x1440.png` | ✅ |
| 无 Logo 宣传图（Windows） | 横 ≥1920×1080、竖 ≥720×1080，<6MB，**完全无文字** | `materials/promo_nologo_1920x1080.png`、`promo_nologo_720x1080.png` | ✅ |
| 游戏截图 \*必填 | ≥3 张，横图比例 8:3~8:5，单张 <4MB，实机≥50% | 复用 `steam/store/screenshots/`（1920×1080，16:9 在范围内） | ✅ |
| 简介 \*必填 | 前 50 字最抓人 | 见下方文案 | ✅ |
| 更新日志 \*必填 | 有序列表 | 见下方文案 | ✅ |
| 开发者的话 | 设计理念，别和简介重复 | 见下方文案 | ✅ |
| **游戏实机录屏** \*下载/试玩必填 | MP4/MOV，>15 秒，前 5 秒展示核心玩法，无配音无贴片 | — | ❌ **还缺，需要录屏** |

重新生成物料：

```powershell
python taptap\scripts\make_materials.py
```

> 宣传图/封面是**程序化绘制的拓扑主视觉**，不是游戏截图拼贴，符合「不得直接使用游戏截图」这条；
> 壁纸和无 Logo 宣传图完全没有文字。若审核对英文名也较真，`materials/` 里已只保留中文名。

## 四、文案（直接抄）

**简介（必填，前 50 字最重要）**

```
你是深夜唯一的安全值班员。10 个小时、6 条攻击链、每回合 6 点行动点：调查、控制、清除、恢复，顺序错了公司被打穿，下手重了业务先崩。回合制安全运营玩法，支持命令行人机命令与自动化脚本三种操作方式。
```

**开发者的话**

**更新日志（必填）**

1. 新增安全加固树：三条线 × 两层，第二层三选一

## 五、提交顺序（用 telling工作室 直接发）

1. 左侧图标栏 → **游戏管理（商店）** → 新建游戏（厂商选「telling工作室」，别点「新增厂商」）
2. 填「游戏资料」：名称、简介、开发者的话、类型标签
3. 传物料：按第三节表格顺序（图标 → LOGO → 封面 → 壁纸 → 宣传图 → 截图 → 录屏）
4. 传**游戏资质**：软著登记号 + 证书扫描件（若要开放下载再加版号 + 核发单）
5. 右上角「提交审核」→ 等 1–3 个工作日
6. 审核通过后，PC 版还要在后台**传包**（上传工具：TapTap PC 游戏包上传工具）

## 六、我的建议

- **软著现在就去申请**（约 30–60 个工作日，可加急）。这是唯一必要且能立刻启动的事。
- **版号别自己硬扛**：PC 单机在 TapTap 也要版号，个人基本走不通，考虑代理或用「预约页」过渡。
- **同时先发 Steam + itch.io**：这两个不需要版号，物料已经齐全，Steam 只差 AppID。
- TapTap 的「预约页」可以把这批发好的物料全用上，先攒关注等资质。
